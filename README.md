# Restaurant Rating Prediction using Machine Learning

## Objective
To build a regression model that predicts restaurant aggregate ratings based on various features.

## Steps Performed
- Data preprocessing
- Handling missing values
- Encoding categorical variables
- Train-test split
- Model training using Linear Regression / Decision Tree
- Model evaluation

## Evaluation Metrics
- Mean Squared Error (MSE)
- R-squared Score

## Tools Used
- Python
- Pandas
- Scikit-learn
- VS Code
